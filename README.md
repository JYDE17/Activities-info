# Activities-info

Petite application **locale** de consultation des activités GoPlex. Quand le
personnel veut plus d'infos sur une activité, il clique dessus et voit tout
(prix, conditions, VIP). Une instance par POS, sur le même modèle que StoreInfo.

Aucune installation : ouvre `index.html`. Toutes les données se modifient dans
**`activites.js`**. Voir `LISEZMOI.md` pour les détails.
