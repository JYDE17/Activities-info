# Activities-info

Application locale d'impression des **fiches d'activités** GoPlex (prix,
conditions, VIP) sur imprimante thermique via QZ Tray — une instance par POS,
sur le même modèle que StoreInfo.

Ouvre `index.html`, clique une activité, imprime. Toutes les données se
modifient dans **`activites.js`**. Voir `LISEZMOI.md` pour les détails.
